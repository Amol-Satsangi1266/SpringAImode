# Spring AI Exploration

A repository dedicated to experimenting with and building Spring AI applications using Spring Boot.

## Overview
This project showcases practical implementations of AI capabilities within the Spring ecosystem. It covers portable APIs, retrieval-augmented generation (RAG), tool calling, and structured outputs.

## Key Topics
* **ChatClient API:** Fluent prompt design and system instructions.
* **Multi-Provider Support:** Integrating models from OpenAI, Anthropic, Ollama, and Google.
* **Tool Calling:** Exposing Java functions for AI workflows.
* **RAG:** Document ingestion, embeddings, and vector store integration.
* **Memory:** Managing conversation state and advisors.

## Tech Stack
* Java 17+
* Spring Boot
* Spring AI
* Maven / Gradle
